
GIT - Source code management software  -- SCM

------------------
1) Working Directory:

-actual project code where changes are making

# touch
# git restore filename (restore file from staging area)
# ls -la (to check .git folder and all hidden files)

-----------------
2) Staging Area: (tracked/ untracked files)

# git add .
# git status
# git rm --cached index.html

-temp storing area, changes selected for the next commit

-can restore file from staging area to working directory

-The main reason is to select exactly you what to commit

-----------------
3) Commit: (Final committed  files)

# git commit -m "This is My first commit"   (Wil ask to enter username and email)

/opt/travelproject/.git/config  ( Needs to update info manually) OR

# git config --global user.name ramu
# git config --global user.email ramu@gmail.com

# cat /root/.gitconfig
# git show  (to check latest commit)
# git ls -files ( to check all committed files)
# git log ( all log with details)

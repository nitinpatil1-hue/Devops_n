MySecondPipeline Project

Add below code :

pipeline {
	    agent any

	    stages {
	        stage('Clone from GitHub') {
	            steps {
	                git branch: 'main', url: 'https://github.com/khotrakesh94/MyFinanceProject.git'
	            }
	        }

	        stage('Deploy to Nginx Server') {
	            steps {
	                sshagent(credentials: ['nginx-creds']) {
	                sh '''
	                    echo "Deploying index.html to remote Nginx server..."
	                    scp -o StrictHostKeyChecking=no index.html ubuntu@13.126.222.220:/var/www/html/
	                    echo "Deployment completed successfully!"
	                '''
	                }
	            }
	        }
	    }
	}

1) if we want to run linux commands in jenkins then use sh before command

2) to run multiple commmand in one go then
# sh ''' ls df-h touch '''

3)
scp -o StrictHostKeyChecking=no
is commonly used in Jenkins when Jenkins needs to copy files to or from 
a remote server over SSH without getting stuck on the SSH host-key confirmation prompt

Nodejs Project on application server : 

Launch App Server
Install Nodejs

cd /opt/nodejsproject1/app.js


app.js 
-----
const http = require("http");

const server = http.createServer((req, res) => {

    if (req.url === "/" && req.method === "GET") {
        res.writeHead(200, { "Content-Type": "text/html" });
        res.end("Hello World");
    }

});

server.listen(3000, () => {
    console.log("Server running on port 3000");
});
